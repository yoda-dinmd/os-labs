# Lab 5 — The File System with Your Own Hands

**Submitted report: [Lab 5 PDF](../reports/lab5.pdf).**

This laboratory explores Linux file types, inodes, hard and symbolic links, permissions, disk layout and procfs. The report covers every required observation and two optional experiments: gzip signatures and deletion of an open file.
